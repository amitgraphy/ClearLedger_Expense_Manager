One-time Google setup required

For security, you must create a Google Sheet, add the small connector script, and deploy it. Then paste the Web app URL and your chosen access key below. The separate setup guide is included with this download.

Saving to Google Sheets replaces the Transactions and Settings data in the connected spreadsheet with this app's current data. Loading from Sheets replaces this browser's current data. Download a backup first if needed. Use only your own private sheet and keep your access key private.
